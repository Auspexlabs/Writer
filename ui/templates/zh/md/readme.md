## 快速开始

```bash
git clone https://example.com/org/project.git
cd project
npm install
npm run dev
```

打开 http://localhost:3000 即可看到运行结果。

## 配置

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `PORT` | 服务端口 | `3000` |
| `DATABASE_URL` | 数据库连接串 | 无 |
| `LOG_LEVEL` | 日志级别 | `info` |
