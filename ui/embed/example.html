Writer 嵌入示例

Word、Excel、PowerPoint 等编辑器或整个 Writer 放进任意网页：引擎是 WebAssembly，文档只在访问者的浏览器里。接入方式见 docs/embed.md。

<div id="doc" style="height:620px"></div>
<script src="https://你的域名/writer/embed/writer-embed.js"></script>
<script type="module">
  const writer = Writer.embed('#doc', { mode: 'docx', file: '/files/会议纪要.docx' });
  await writer.ready;
  await writer.run('add 会议纪要.docx /body --type paragraph --prop text="由网站写入"');
  const blob = await writer.get('会议纪要.docx');   // 当前文件
</script>

一个编辑器

mode: 'docx'：只有这一个文档，没有标签页和新建页。网站可以用命令改它，也能随时取回文件。



  
整个软件

  
mode: 'app'：标签页、新建页和模板都在；可以同时打开几个文件。

  


  
AI 助手

  
填一个 OpenAI 兼容的接口（最好是你自己的后端转发地址，由后端加上密钥），编辑器右上角会出现 AI 按钮；助手用和桌面版一样的方式改文档，改动可以保留或撤销。网站自己的智能体也可以用 writer.tools() / writer.callTool() 直接操作文档。
