# Writer 0.1.8

Office 编辑、原生文件保存与撤销增强，PDF 资源随应用离线分发。完整实现和尚未完成的范围见 [实施状态](../office-implementation-status.md)。本版不代表 Microsoft Office 全功能对等。

- Word：修复跨段落批注、对象显示与保存删除、页眉页脚及命令撤销；MathType WMF 预览转换；加入分节不同纸张、跨页表格与重复表头、页眉表格单元格编辑、范围书签、跨表书签引用和表格公式、行内表单与 XML 绑定、邮件合并数据源和标签信封、通配符及格式查找、行号和断字。
- Excel：取消 80×20 网格显示限制，修复合并撤销保存与区域排序；加入多区域剪贴板、名称及三维引用、迭代计算、高阶数组和统计债券函数、查询步骤、多字段透视、计算字段和项目分组、规划求解、方案及模拟运算表、迷你图、分列、高级筛选、颜色／图标／自定义序列排序、单元格与行列继承保护、密码设置／解锁、工作簿结构密码、成组工作表同步编辑、独立拆分窗格、快速填充、透视操作权限、细分插删和选择权限、逐步公式求值、可点击的跨表依赖箭头。
- PowerPoint：按实际字号显示；加入组合成员编辑、选择窗格、字体替换、大纲、讲义备注打印、矢量折线和二次／三次贝塞尔顶点与控制柄编辑、自定义放映、媒体剪辑与字幕、跨页音频及更多动画设置。
- Word／PowerPoint：原生图表和四类 SmartArt 的数据／节点编辑，保留嵌入工作簿与保存历史。
- 学术写作：首页新增 MLA、APA、Chicago 论文模版；打开论文时认出引用格式，AI 面板问一句即可开启写作辅助——引文和书目按格式排版，写完一段自动检查拼写、语法和格式（要删的字划线、有问题处画波浪线，Tab 接受），Works Cited 页底下粘贴网址、DOI 或整条参考文献即成条目；引擎新增 `POST /ask`。
- PDF：本地 PDF.js、worker、字体、中文 CMaps 与 pdf-lib；离线浏览、搜索、批注、表单填写保存和页面处理。无需首次连接 CDN。

原生 995 项、界面与桥接 1203 项回归通过。实际浏览器覆盖三个编辑器的保存重开与撤销，另阻断外网验证 PDF 本地资源。仍需补齐复杂多栏、完整修订与域、M／DAX、高级透视、完整母版／动画、云协作及办公生态等。普通百万公式输入已优化，原生保存峰值内存仍需继续下降。
