# Writer 标志资源

- `writer-mark.svg`：透明底的独立 W 图标，可用于 favicon 与小尺寸入口。
- `writer-logo.svg`：独立 W 直接衔接 `riter`，组成完整 Writer 字标。
- `writer-mark-1024.png`：1024 × 1024 透明 PNG 图标。
- `writer-logo-2048.png`：2048 × 827 透明 PNG 横版标志。

采用用户选定的第二款 Georgia Bold 衬线 W 与第一款透明无底方案，W 后仅衔接 `riter`。两个 SVG 均为透明背景和纯矢量路径，无须安装字体即可使用。`riter` 与 W 同样依据 Georgia Bold 绘制，并做紧凑的字距与略窄的字形调整，使 W 与 r 形成一个连续字标；W 的路径保持不变。

为便于与 B/C 文件图标一同取用，这四份资源也复制到 `file-icons/logos/` 和 `../ui/assets/`。
