# Writer 文件类型图标 · 待选方案

保留 B、C 两套原创 SVG 概念图，每套包含六种文件类型。所有图标均为 64 × 64 视图框，可独立缩放。

| 编号 | 风格 | 路径 |
| --- | --- | --- |
| B1–B6 | 雾彩玻璃 | `concepts/b-glass/` |
| C1–C6 | 深色几何 | `concepts/c-solid/` |

每套编号依次对应 Word、Excel、Markdown、思维导图、PPT、PDF。B3、C3 使用与各自套系一致的底色、Georgia Bold 大写 A 与输入光标；B6、C6 使用更细的 PDF 字样和边框。可以选择整套，也可以按文件类型混搭。两套资源已复制到 `ui/assets/icons/{b,c}/`，随软件发布包一起交付；官网对比页位于 `/icon-lab`。未选用的 A 套保存在 `archive/a-outline/`。

`logos/` 保存独立 W 与完整 Writer 字标的 SVG 和透明 PNG 副本；对应的软件资源位于 `ui/assets/`，品牌原稿位于 `brand/`。
