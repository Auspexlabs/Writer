| `02-ai.png` | AI 帮你写、帮你改 | 改动直接写进文档并标出来，一键保留或撤销；可接入 DeepSeek、通义千问、Kimi 等模型 | 周报旁边打开 AI 面板：一条请求、助手的回复、执行的命令、改动列表和「保留 / 撤销」，文档里的改动标成绿色 |

## 重新生成

```bash
node desktop/store/screenshots/src/shots.mjs          # 全部
node desktop/store/screenshots/src/shots.mjs 02 05    # 只重拍其中几张
```

需要 macOS、dotnet 和 Google Chrome，屏幕上不会打开任何窗口。脚本依次：构建引擎（缺 `writer-vision` 时一起构建）；在临时目录里画示例照片、用 `writer` 命令生成示例文档；启动 `writer serve --no-token --ui ui`；用无头 Chrome 打开 `mac.dc.html?native=1`，通过应用自己的菜单和按钮摆好每个画面，截下窗口；最后套上 `frame.html` 的标题和背景输出到 `zh-Hans/`，并检查尺寸和 alpha。界面改版后重跑即可。

可选环境变量：`SHOTS_TMP`（临时目录）、`KEEP=1`（保留临时目录，里面有示例文档和窗口原图）、`SHOTS_TZ`（时区，默认 `Asia/Shanghai`）、`CHROME`（Chrome 路径）。

| `src/` | 作用 |
|---|---|
| `shots.mjs` | 入口：每张图的标题、打开的文件和摆拍步骤，截图与合成 |
| `make-samples.sh` | 用 `writer create / add / set` 生成示例文档（内容都是虚构的） |
| `photo.html` | 用 Canvas 画的拿铁俯拍照片，截图里没有第三方图片 |
| `mock-model.mjs` | 本地模拟的模型接口（OpenAI 兼容流式接口，引擎按「自定义」服务商连接），不调用真实模型 |
| `frame.html` | 画布：背景、标题、副标题、窗口的圆角和阴影 |
| `cdp.mjs` | 通过 `--remote-debugging-pipe` 驱动无头 Chrome，不占端口 |

## 说明

- 窗口按应用默认大小 1280 × 800 渲染，截取时每点 1.65 像素，放进 2880 × 1800 的画布后一比一，不再缩放；交通灯和标题栏是 `mac.dc.html` 自己画的。
- AI 截图里，模型的回复来自 `mock-model.mjs`，它给出的 `writer` 命令由引擎真实执行；绿色改动标记、改动列表和「保留 / 撤销」都是应用自己画的。
- 抠图是在应用里选中图片、打开「图片」标签、点「抠图」完成的，由 `writer-vision`（Apple Vision）处理。
- 批注时间按北京时间显示（无头 Chrome 的时区设为 `Asia/Shanghai`）。
- 03 放大到 120% 时表格绕视图中心缩放，A 列（月份）会滚出视图，所以放大后滚回 A1。
- 一处画面绕开了当前界面的问题，修好后可以换回更直接的做法：
  - 幻灯片「图片」工具按对象 id 在所有页里找图片，前面某页若有同 id 的形状就会改错对象（抠图提示 “shape has no property 'background'”），所以带照片的那页放在第 2 页。
